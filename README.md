### 💡 About This Project: The Data Validation Upgrade

Unlike standard competitive programming repositories that assume perfect inputs, this project implements **defensive programming**. I have upgraded these solutions to include strict data validation and custom exception handling. 

Real-world applications crash when fed bad data. To bridge the gap between algorithmic puzzles and production-ready software, these solutions actively reject invalid inputs (such as unsorted arrays when a sorted one is required or integer overflows) by throwing specific exceptions (`IllegalArgumentException`, `ArithmeticException`, etc.).

**Key Features:**
* **Defensive Mechanisms:** Prevents bad inputs from silently producing incorrect results.
* **Custom Utilities:** A dedicated `utils` folder containing custom data structures (`ListNode`, `TreeNode`) and helper methods (like `ArrayUtils` and `ListUtils`) to build and validate test cases.
* **Extensive Documentation:** All custom exception triggers and personalized messages are thoroughly documented in the repository's [Wiki](link-to-your-wiki).
